# Лабораторная работа 3

## Задание

Задача 3. Реализовать функцию `chunkArray(arr, size)`, которая разбивает массив
на подмассивы указанного размера. Последний подмассив может быть короче `size`.

## Реализация

Решение находится в ES-модуле `solution.js`. Функция `chunkArray` доступна через
именованный экспорт и возвращает новый массив подмассивов.

Цикл проходит по исходному массиву с шагом `size`. Метод
`arr.slice(index, index + size)` копирует очередную часть, которая добавляется в
результат. Исходный массив не изменяется, порядок элементов сохраняется. Для
пустого массива возвращается `[]`. Если `size` превышает длину массива,
результат содержит один подмассив со всеми его элементами.

Аргумент `arr` должен быть массивом, иначе выбрасывается `TypeError`. Аргумент
`size` должен быть положительным целым числом, иначе выбрасывается `RangeError`.

## Запуск

Для запуска необходим Node.js с поддержкой ES-модулей. Откройте PowerShell в
папке с `solution.js` и выполните:

```powershell
@(
  Get-Content -Raw .\solution.js
  'console.log(JSON.stringify(chunkArray([1, 2, 3, 4, 5], 2)));'
  'console.log(JSON.stringify(chunkArray([], 2)));'
  'console.log(JSON.stringify(chunkArray([1, 2], 5)));'
) | node --input-type=module
```

Ожидаемый вывод:

```text
[[1,2],[3,4],[5]]
[]
[[1,2]]
```

Команда передаёт содержимое файла и примеры вызова в Node.js в режиме ES-модуля.
Для вывода результатов используется `console.log` в команде запуска.
