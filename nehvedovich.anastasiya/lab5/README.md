# Лабораторная работа 5

## Задание

Вариант 38. Создайте список книг в магазине. Сверху справа расположите кнопку
переключения темы. Реализуйте логику для изменения режима отображения в
приложении с помощью Context API. 115 Функциональность: - кнопка меняет свое
название (иконки) в зависимости от выбранного режима; - для каждого цвета
светлой темы, должен быть подобран альтернативный цвет в темной теме.
Примечание: Нельзя использовать дизайн библиотеки. Используемые технологии
согласовать с преподавателем (если такие будут).

## Реализация

- создан список книг в магазине;
- кнопка переключения темы расположена сверху справа;
- состояние темы хранится и передаётся через React Context API;
- кнопка меняет иконку и подпись в зависимости от активного режима;
- для каждого основного цвета светлой темы задан альтернативный цвет тёмной темы
  через CSS-переменные;
- дизайн-библиотеки не используются;
- выбранная тема дополнительно сохраняется в `localStorage` и восстанавливается
  после перезагрузки страницы.
